This is the accompanying code repository to our datasets Beethoven Symphony Excerpt Dataset (BSED) and Beethoven Symphony Dataset (BSD). We will publish the code soon after some final checks and cleanups!

The data can be found on [Zenodo.](https://zenodo.org/records/20344500)

If you use BSED/BSD in your academic work, please cite this article:
